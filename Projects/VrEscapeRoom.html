About This Project

Technology Used:
• Unity Game Engine
• C# scripting
• XR Interaction Toolkit
• VR controllers
• Teleport locomotion
• Apartment Kit asset pack
• Oculus Quest 2

Features:
• VR escape room set in a realistic apartment
• Four main puzzles with interactive VR controller interactions
• Hidden-key puzzle, keypad puzzle, object placement challenge, and riddle-based final puzzle
• Hand interactions and physics-based objects
• Immersive environment design with natural VR movement

Target Audience:
• Casual to experienced VR players
• Puzzle lovers and curious explorers
• Age group 16–35
• Puzzle solvers, explorers, and speed runners
• Individuals interested in mystery and interactive storytelling

Challenges Faced:
• Setting up working VR interactions and controller debugging
• Configuring colliders and triggers for object interaction
• Handling object grabbing and placement accuracy
• Creating puzzle logic that connects between rooms
• Keeping the environment realistic and readable
• Optimizing the scene to run smoothly in VR without lag or motion sickness
